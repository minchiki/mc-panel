# Свой Minecraft-сервер за 10 минут

Ничего знать не нужно. Просто делайте по порядку: **нажми сюда, вставь это, вставь вот это.**

## Шаг 1. Купите VPS

VPS - это компьютер в интернете, на котором будет жить ваш сервер.

Купите у любого хостинга VPS и выберите:
- система: **Ubuntu 24.04** (или 22.04)
- память: **от 2 ГБ** (лучше 4 ГБ)
- диск: **от 20 ГБ**

Когда сервер создастся, в личном кабинете хостинга найдите две вещи и **запишите**:
- **IP-адрес** (четыре числа через точки, например `203.0.113.10`)
- **пароль** от пользователя `root`

---

## Шаг 2. Откройте порты

В личном кабинете хостинга найдите **файрвол** (он же «группа безопасности», «правила доступа») и разрешите **входящие**:

| Порт | Тип |
|---|---|
| `22` | TCP |
| `80` | TCP |
| `443` | TCP |
| `25565-25665` | TCP и UDP |

Без этого шага панель не откроется. Не пропускайте.

---

## Шаг 3. Подключитесь к VPS

**Windows:** нажмите клавиши **Win + X** → выберите **Терминал** (или PowerShell).
**Mac:** откройте программу **Терминал**.

Вставьте (замените `203.0.113.10` на ваш IP) и нажмите **Enter**:

```
ssh root@203.0.113.10
```

- Спросит `yes/no`: напишите `yes`, Enter.
- Спросит пароль: введите пароль от `root` и Enter. Пока вы печатаете, на экране **ничего не видно, это нормально**.

Увидели строку вроде `root@vm-123:~#`? Вы на сервере. Дальше.

---

## Шаг 4. Вставьте две команды

Сначала **эту** (вставка в терминал: правая кнопка мыши), потом Enter:

```
curl -fsSL https://raw.githubusercontent.com/minchiki/mc-panel/main/scripts/bootstrap.sh -o bootstrap.sh
```

Потом **эту**, потом Enter:

```
sudo bash bootstrap.sh
```

Подождите **3-7 минут**. Бегут зелёные строки, ничего не нажимайте. В конце будет:

```
==> done: http://ВАШ_IP/
```

---

## Шаг 5. Узнайте пароль

Вставьте и нажмите Enter:

```
cat /root/mc-panel-admin.txt
```

Появятся `login` и `password`. Выделите пароль мышкой и скопируйте.

---

## Шаг 6. Откройте панель

В браузере откройте `http://ВАШ_IP/` (например `http://203.0.113.10/`) и войдите с этим логином и паролем.

Сразу смените пароль: меню справа вверху → **Аккаунт** → **Пароль**.

---

## Шаг 7. Создайте сервер

1. Нажмите **Серверы** → **Создать сервер**.
2. Введите любое название.
3. Ядро оставьте **Paper**, выберите **версию** (такую же, как в вашем Minecraft).
4. Память: **2 ГБ**.
5. Поставьте галочку **EULA**.
6. Нажмите **Создать**, подождите минуту, нажмите **Запустить**.

---

## Шаг 8. Заходите играть

1. В карточке сервера скопируйте **адрес**.
2. Minecraft Java Edition → **Сетевая игра** → **Добавить сервер** → вставьте адрес → **Готово**.
3. Отправьте этот же адрес друзьям.

**Готово!** 🎉
