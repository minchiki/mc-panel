# Свой Minecraft-сервер и панель управления на VPS: пошаговая инструкция

Инструкция в двух частях:
- **[Часть 1. База](#часть-1-база)**: всё, что нужно новичку, чтобы получить работающий сервер. Умение программировать не нужно, только копировать команды и нажимать кнопки. Примерно 20-30 минут, из них около 5 минут установка идёт сама.
- **[Часть 2. Для продвинутых](#часть-2-для-продвинутых)**: домен и HTTPS, плагины и моды, бэкапы, помощники, ручная настройка, диагностика, безопасность, удаление.

Если хочется быстрее и короче, есть [установка за 10 минут](QUICKSTART.md). Сервер на приветственные бонусы в облаке Сбера: [CLOUDRU.md](CLOUDRU.md).

**Что получится:** на вашем VPS работает веб-панель. Через неё вы создаёте серверы Minecraft, ставите плагины и моды, делаете бэкапы и приглашаете друзей-помощников. Всё в браузере, без консоли.

## 1. Что нужно

| Что | Зачем |
|---|---|
| **VPS** (виртуальный сервер) | на нём будет работать панель и игра |
| **Minecraft: Java Edition** | чтобы зайти на свой сервер |
| Компьютер с интернетом | чтобы управлять VPS (Windows 10/11, macOS или Linux) |

### Какой VPS нужен

| Параметр | Минимум | Комфортно |
|---|---|---|
| Система | **Ubuntu 22.04 или 24.04** | Ubuntu 24.04 |
| Оперативная память | 2 ГБ (один маленький сервер на 2-3 друзей) | 4-8 ГБ (несколько серверов, моды) |
| Процессор | 2 vCPU | 4 vCPU |
| Диск | 20 ГБ | 40 ГБ и больше (миры и бэкапы быстро растут) |
| Адрес | белый (публичный) IPv4 | |

Панель и система занимают около 1 ГБ памяти, остальное идёт на сами серверы.

**Не подойдут:** VPS на Windows (нужен Linux: Ubuntu или Debian), бесплатные хостинги Minecraft и «шаред-хостинг» сайтов (там нет прав администратора root).

## 2. Создайте VPS

**На бонусах:** в облаке Сбера (Cloud.ru) новым пользователям дают приветственные бонусы (4000 Б, примерно на 2 месяца, нужна банковская карта). Пошаговая инструкция по кнопкам: [CLOUDRU.md](CLOUDRU.md).

**Или у любого другого хостинга:**
1. Закажите VPS с **Ubuntu 24.04** (или 22.04) и характеристиками из таблицы выше. Нужен root-доступ.
2. При создании вам дадут или предложат придумать **пароль для пользователя root** (или попросят загрузить SSH-ключ).
3. Когда сервер создастся, найдите в личном кабинете его **IP-адрес** (четыре числа через точки, например `203.0.113.10`). **Запишите его.**

---

## 3. Откройте порты

У хостинга есть **файрвол** (его называют «группа безопасности», «Security Group», «правила доступа»). Он по умолчанию закрывает почти всё. В его настройках в личном кабинете разрешите **входящие** подключения:

| Порт | Протокол | Зачем |
|---|---|---|
| **22** | TCP | вход на VPS по SSH (шаг 4) |
| **80** | TCP | сайт панели |
| **443** | TCP | сайт панели по HTTPS (если подключите домен) |
| **25565-25665** | **TCP и UDP** | сами Minecraft-серверы |

> Если пропустить этот шаг, установка пройдёт, но **панель не откроется** и друзья не смогут зайти. Это самая частая ошибка новичков.

## 4. Подключитесь к VPS

Команды вы будете вводить на самом VPS через **SSH**.

**Windows 10/11:** нажмите **Win + X** и выберите **Терминал** (или Windows PowerShell). **macOS и Linux:** откройте программу «Терминал».

Введите (подставьте свой IP) и нажмите Enter:

```
ssh root@203.0.113.10
```

1. На вопрос `Are you sure you want to continue connecting?` напишите `yes`, Enter.
2. Введите пароль root. **Пока вы печатаете, на экране ничего не появляется, это нормально.** Введите пароль целиком и нажмите Enter.

Получилось, если вы видите строку примерно такого вида:

```
root@vm-12345:~#
```

Теперь все команды ниже вводятся здесь.

> **Вставка в терминал:** в Windows Terminal и PowerShell вставка делается **правой кнопкой мыши** или `Ctrl+V`. В веб-консоли хостера иногда `Ctrl+Shift+V`.
>
> Если вход идёт не под `root`, а под другим пользователем (например `user1` в облаке Сбера или `ubuntu`), войдите и сразу выполните `sudo -i`, чтобы стать root. В облаке Сбера вход по SSH с паролем отключён: используйте **«Виртуальную консоль»** в карточке машины ([инструкция](CLOUDRU.md#шаг-5-подключитесь-к-серверу)).

## 5. Установите панель

Выполните **по очереди** две команды. Сначала скачайте установщик:

```sh
curl -fsSL https://raw.githubusercontent.com/minchiki/mc-panel/main/scripts/bootstrap.sh -o bootstrap.sh
```

Затем запустите его:

```sh
sudo bash bootstrap.sh
```

Установщик сам поставит всё нужное и запустит панель. Побегут зелёные строки `==>`. **Займёт это 3-7 минут, окно не закрывайте.** В конце появится:

```
==> done: http://203.0.113.10/
```

Это адрес вашей панели.

> **Остановилось с ошибкой?** Прочитайте красную строку `ОШИБКА` или `ERROR`. Установщик можно безопасно запустить повторно: он продолжит с того же места. Типичные причины: [раздел 9](#9-если-что-то-не-работает).

## 6. Первый вход

1. Узнайте логин и пароль администратора:
   ```sh
   cat /root/mc-panel-admin.txt
   ```
   Появятся `login: admin` и `password: ...`. Пароль длинный, его проще **скопировать** выделением мыши.
2. Откройте в браузере `http://ВАШ_IP/` (например `http://203.0.113.10/`) и войдите.
3. **Сразу смените пароль:** меню справа вверху → «Аккаунт» → «Пароль».
4. Включите **двухфакторную защиту (2FA)** там же (понадобится приложение вроде Google Authenticator).
5. Когда записали новый пароль, удалите файл с первым:
   ```sh
   rm /root/mc-panel-admin.txt
   ```

> Браузер может написать «Не защищено»: адрес без HTTPS. Для начала это нормально, домен с HTTPS подключается во [второй части](#11-домен-и-https).

## 7. Создайте сервер Minecraft

1. В панели откройте **«Серверы»** → **«Создать сервер»**.
2. Выберите **ядро**. Коротко: **Vanilla**, если нужна обычная игра без изменений; **Paper**, если хотите плагины (дом, приваты, экономика); **Fabric**, **Forge** или **NeoForge**, если нужны моды. Подробная таблица ядер: [во второй части](#10-ядра-minecraft).
3. Выберите **версию**: такую же, как в вашем Minecraft (в лаунчере). Java подберётся сама.
4. Укажите **память**: оставьте 1 ГБ запаса от памяти VPS (на VPS с 4 ГБ серверу можно 2-3 ГБ).
5. Поставьте галочку **EULA** (обязательное соглашение Mojang).
6. Нажмите «Создать сервер». Пойдёт установка, около минуты (в первый раз до пары минут: качается Java).
7. Когда появится «Установка завершена», нажмите **«Запустить»**. Первый запуск создаёт мир, 30-90 секунд. Готово, когда в консоли строка `Done (...)! For help, type "help"`.

---

## 8. Зайдите на сервер

1. Адрес показан в карточке сервера в панели, например `203.0.113.10` или `203.0.113.10:25566`.
2. В Minecraft Java Edition **той же версии**: «Сетевая игра» → «Добавить сервер» → вставьте адрес → «Готово».
3. Друзьям отправьте тот же адрес.

> Не заходит, хотя в панели сервер «Онлайн»? С вероятностью 90% закрыты порты в файрволе ([шаг 3](#3-откройте-порты)).

---

## 9. Если что-то не работает

**Панель не открывается в браузере.**
1. Проверьте порт **80** в файрволе хостера ([шаг 3](#3-откройте-порты)): причина в 9 случаях из 10.
2. Адрес должен быть `http://` (не `https://`), если домен не подключали.

**Друзья не могут зайти.**
- Открыты ли порты **25565-25665** (TCP) в файрволе?
- Версия Minecraft у друга совпадает с версией сервера?
- Адрес с портом (`IP:25566`), если сервер не первый?

**Сервер сам выключается при запуске.** Не хватает памяти: значение «Память» в настройках сервера слишком большое. Уменьшите его (оставьте 1 ГБ запаса) или возьмите VPS побольше.

**Ничего не помогло.** Напишите боту поддержки **[@faqmcpanel_bot](https://t.me/faqmcpanel_bot)** в Telegram: он подскажет, а если не справится, позовёт разработчика. Подробный разбор проблем: [вторая часть](#16-диагностика).

## 10. Ядра Minecraft

| Ядро | Когда выбирать |
|---|---|
| **Vanilla** | чистый Minecraft без изменений |
| **Paper** | игра с друзьями, плагины (дом, приваты, экономика), хорошая скорость |
| **Purpur / Spigot** | как Paper, с дополнительными настройками (Spigot собирается 5-10 минут) |

Список версий берётся из официальных API. Java 8/17/21/25 подбирается под версию автоматически, её можно поменять в настройках сервера.

## 11. Домен и HTTPS

Домен (например `moy-server.ru`) делает адрес запоминающимся, а HTTPS включает шифрование и убирает предупреждение «Не защищено».

1. Купите домен у любого регистратора.
2. В DNS домена создайте **A-запись**: имя `panel` (получится `panel.moy-server.ru`), значение: IP вашего VPS. Подождите 5-30 минут, пока запись разойдётся.
3. На VPS выполните (подставьте свой домен и почту):
   ```sh
   DOMAIN=panel.moy-server.ru EMAIL=you@example.com bash /opt/mc-panel/scripts/install.sh
   ```
4. Панель будет доступна по `https://panel.moy-server.ru/`. Сертификат продлевается автоматически (`certbot.timer`).

Игровой адрес вида `play.moy-server.ru` настраивается во вкладке сервера **«Сеть»**: там подсказки по A- и SRV-записям.

## 12. Плагины, моды, бэкапы, помощники

**Плагины и моды.** Вкладка сервера **«Плагины»** (Paper и похожие) или **«Моды»** (Fabric, Forge, NeoForge): поиск по Modrinth, Hangar, SpigotMC и CurseForge (для CurseForge нужен ключ в «Настройки панели»). «Установить», затем перезапустите сервер.

**Бэкапы.**
- Вкладка **«Бэкапы»**: кнопка «Создать». Восстановить или скачать можно в один клик.
- Автоматические: вкладка **«Расписание»** → «Бэкап»: как часто и сколько копий хранить.
- Сама панель каждую ночь сохраняет свою базу в `/var/backups/mc-panel`. Вручную: `sudo /opt/mc-panel/scripts/backup.sh`.

> Бэкапы лежат на том же VPS. Если VPS удалят или он сломается, пропадут и они. Важные миры скачивайте к себе на компьютер.

**Помощники.** **Администрирование → Пользователи**: создайте друзьям отдельные аккаунты и выберите, какие разделы им доступны (консоль, файлы, игроки). Пароль админа никому не отдавайте.

**Где что лежит.**

| Путь | Что там |
|---|---|
| `/opt/mc-panel` | код панели (git) |
| `/etc/mc-panel/.env` | секреты и настройки (права 600) |
| `/var/lib/mc-panel/panel.db` | база панели (SQLite) |
| `/srv/minecraft/servers/<id>/` | файлы игровых серверов |
| `/srv/minecraft/backups/<id>/` | бэкапы игровых серверов |

## 13. Обновление панели и пароль админа

**Обновление.** Кнопка **«Настройки панели» → «Обновить панель»** или в консоли VPS:
```sh
sudo /opt/mc-panel/scripts/update.sh
```
Игровые серверы при этом **не выключаются**. Перед обновлением панель делает свою резервную копию. Откат на прошлую версию:
```sh
cd /opt/mc-panel && sudo git log --oneline       # найти нужный коммит
sudo git checkout <commit> && sudo scripts/build.sh && sudo systemctl restart mc-panel
```

**Потерян пароль администратора:**
```sh
cd /opt/mc-panel/server && sudo -u mcpanel env $(sudo cat /etc/mc-panel/.env | xargs) node dist/cli.js reset-password admin
```
Команда выведет новый пароль. Есть также `disable-2fa <user>` и `create-admin <user>`.

## 14. Настройки установщика

`bootstrap.sh` и `install.sh` настраиваются переменными окружения:

| Переменная | Что делает |
|---|---|
| `PUBLIC_HOST` | IP или домен, который видят игроки (по умолчанию определяется сам) |
| `DOMAIN`, `EMAIL` | вместе включают HTTPS (Let's Encrypt) |
| `ADMIN_USER` | логин первого администратора (по умолчанию `admin`) |
| `REPO_URL`, `BRANCH` | откуда ставить панель (для форков и тестов) |

Пример: `sudo PUBLIC_HOST=203.0.113.10 ADMIN_USER=boss bash bootstrap.sh`. Если Docker, Node.js ≥ 22.13 и nginx уже стоят, `bootstrap.sh` можно пропустить: `sudo bash /opt/mc-panel/scripts/install.sh`.

## 15. Консольные команды сервера

## 16. Диагностика

**Панель не открывается, порт 80 открыт.** Проверьте службу:
```sh
systemctl status mc-panel
curl http://127.0.0.1:3000/api/health
journalctl -u mc-panel -n 50 --no-pager
```
Нужны `active (running)` и ответ `{"ok":true}`.

**Установщик не может скачать Docker, Node.js или панель.** Проблемы с доступом в интернет или к конкретному сайту:
```sh
curl -I https://github.com
curl -I https://deb.nodesource.com
```
Если не отвечает, подождите и запустите установщик заново, либо напишите в поддержку хостинга. Остальные частые вопросы: [FAQ](FAQ.md).

**«Установка не удалась: ... нет связи» при создании сервера.** Панель не смогла скачать ядро с сайта разработчиков. Нажмите «Установить» ещё раз; если повторяется, проверьте на VPS `curl -I https://meta.fabricmc.net` (Fabric) или `curl -I https://fill.papermc.io` (Paper). Админ может открыть в браузере `http://ВАШ_IP/api/admin/network-check`: там видно, какие сайты доступны с VPS и за сколько миллисекунд.

**«Порт занят».** Выберите другой порт во вкладке «Сеть» из диапазона 25565-25665.

**Сервер «убит» при запуске.** Нехватка памяти: `free -h`, уменьшите «Память» сервера.

**Docker не запускается:**
```sh
systemctl enable --now docker
docker info
```
Если `docker info` выдаёт ошибку, на этом типе виртуализации нельзя запускать контейнеры. Закажите VPS на KVM.

**Нужна помощь.** Бот [@faqmcpanel_bot](https://t.me/faqmcpanel_bot) или вопрос (Issue) в репозитории. Приложите название хостинга, версию Ubuntu (`lsb_release -a`) и последние 30 строк `journalctl -u mc-panel -n 30 --no-pager` (пароли и IP замажьте).

## 17. Безопасность

VPS в интернете **сразу** начинают проверять боты: подбирают пароли.

1. **Пароль root: длинный и уникальный** (16+ символов), нигде больше не используйте.
2. **Смените пароль администратора панели** и включите 2FA.
3. **Не открывайте лишние порты** в файрволе, только из [шага 3](#3-откройте-порты).
4. Панель сама банит подбор паролей (fail2ban): 8 неудачных попыток подряд дают бан на час.
5. **Никому не давайте пароль root и пароль админа.** Друзьям создавайте отдельные аккаунты с ограниченными правами.
6. Раз в месяц обновляйте систему (`apt update && apt upgrade -y`) и панель.
7. Для SSH вместо пароля используйте ключи и запретите вход по паролю.

Что защищено внутри: пароли хранятся в argon2id, секреты шифруются AES-256-GCM, серверы запущены в Docker-контейнерах без root, с лимитами ресурсов, своей сетью и доступом только к своей папке. Подробности: [главная страница](../README.md#безопасность).

## 18. Как удалить панель

> Это **безвозвратно удалит все серверы, миры и бэкапы.** Сначала скачайте всё нужное.

```sh
systemctl disable --now mc-panel mc-panel-update.path mc-panel-backup.timer
docker ps -aq | xargs -r docker rm -f
rm -rf /opt/mc-panel /var/lib/mc-panel /srv/minecraft /etc/mc-panel /var/log/mc-panel /var/backups/mc-panel
rm -f /etc/systemd/system/mc-panel*.service /etc/systemd/system/mc-panel*.path /etc/systemd/system/mc-panel*.timer
rm -f /etc/nginx/sites-enabled/mc-panel /etc/nginx/sites-available/mc-panel
systemctl daemon-reload && systemctl reload nginx
```

Либо просто удалите VPS в личном кабинете хостинга.
