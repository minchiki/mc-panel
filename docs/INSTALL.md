# Свой Minecraft-сервер и панель управления на VPS: пошаговая инструкция

Эта инструкция для тех, кто делает это впервые. Умение программировать не нужно: придётся скопировать несколько команд и понажимать кнопки. Времени уйдёт примерно 20-30 минут, из них около 5 минут установка идёт сама.

**Что получится:** на вашем VPS работает веб-панель. Через неё вы создаёте серверы Minecraft (Paper, Fabric, Forge и другие), ставите плагины и моды, делаете бэкапы и приглашаете друзей-помощников. Всё в браузере, без консоли.

## 1. Что нужно

| Что | Зачем | Подробности |
|---|---|---|
| **VPS** (виртуальный сервер) | на нём будет работать панель и игра | см. таблицу ниже |
| **Minecraft: Java Edition** | чтобы зайти на свой сервер | версия для компьютера |
| Компьютер с интернетом | чтобы управлять VPS | Windows 10/11, macOS или Linux |
| Банковская карта (или иной способ оплаты) | VPS платный | обычно 300-1000 руб. в месяц |

### Какой VPS брать

| Параметр | Минимум | Комфортно |
|---|---|---|
| Система | **Ubuntu 22.04 или 24.04** | Ubuntu 24.04 |
| Оперативная память | 2 ГБ (один маленький сервер на 2-3 друзей) | 4-8 ГБ (несколько серверов, моды) |
| Процессор | 2 vCPU | 4 vCPU |
| Диск | 20 ГБ | 40 ГБ и больше (миры и бэкапы быстро растут) |
| Адрес | белый (публичный) IPv4 | |

Почему важна память: панель и система занимают около 1 ГБ. Остальное идёт на сами серверы. Ванильному серверу для небольшой компании хватает 1-2 ГБ, сборкам с модами нужно 4 ГБ и больше.

**Не подойдут:**
- VPS на Windows. Панель работает только на Linux (Ubuntu или Debian).
- Бесплатные хостинги Minecraft и «шаред-хостинг» сайтов. На них нет прав администратора (root).
- Тарифы вообще без Docker. Это редкость, у большинства VPS с Ubuntu всё в порядке.

## 2. Создайте VPS

1. Выберите хостинг и закажите VPS с **Ubuntu 24.04** (или 22.04). Любой хостинг подойдёт, если у него есть VPS с root-доступом.
2. При создании вам дадут или предложат придумать **пароль для пользователя root** (или попросят загрузить SSH-ключ).
3. Когда сервер создастся, найдите в личном кабинете его **IP-адрес** (четыре числа через точки, например `203.0.113.10`). Он понадобится дальше. Запишите его.

> **VPS от Сбера (cloud.ru):** подробные шаги по созданию сервера и открытию портов в облаке Сбера смотрите в отдельной инструкции: [CLOUDRU.md](CLOUDRU.md).

## 3. Откройте порты

У большинства хостингов есть **файрвол** (его называют «группа безопасности», «Security Group», «правила доступа» или «сетевой экран»). Он по умолчанию закрывает почти всё. Зайдите в его настройки в личном кабинете хостинга и разрешите **входящие** подключения:

| Порт | Протокол | Зачем |
|---|---|---|
| **22** | TCP | вход на VPS по SSH (на шаге 4) |
| **80** | TCP | сайт панели |
| **443** | TCP | сайт панели по HTTPS (если подключите домен) |
| **25565-25665** | **TCP и UDP** | сами Minecraft-серверы |

Диапазон 25565-25665 нужен потому, что на одном VPS можно сделать много серверов: первый получит порт 25565, второй 25566 и так далее.

> Если вы пропустите этот шаг, установка пройдёт, но **панель не откроется** в браузере и друзья не смогут зайти. Это самая частая ошибка новичков.

## 4. Подключитесь к VPS

Вы будете вводить команды на самом VPS через **SSH**. Это как «удалённый терминал».

### Windows 10/11

1. Нажмите **Win + X** и выберите **Терминал** или **Windows PowerShell**.
2. Введите (подставьте свой IP) и нажмите Enter:
   ```
   ssh root@203.0.113.10
   ```
3. На вопрос `Are you sure you want to continue connecting?` напишите `yes` и нажмите Enter.
4. Введите пароль root. **Пока вы печатаете пароль, на экране ничего не появляется. Это нормально.** Просто введите его целиком и нажмите Enter.

### macOS и Linux

Откройте программу «Терминал» и выполните ту же команду: `ssh root@203.0.113.10`.

### Как понять, что всё получилось

Вы увидите приветствие Ubuntu и строку примерно такого вида:

```
root@vm-12345:~#
```

Теперь все команды ниже вводятся здесь.

> **Вставка в терминал:** в Windows Terminal и PowerShell вставка делается **правой кнопкой мыши** или `Ctrl+V`. В окне хостера (веб-консоль) бывает `Ctrl+Shift+V`. Если вставилась «каша», введите команду руками.
>
> Если вход идёт не под `root`, а под другим пользователем (например `ubuntu`), сначала выполните `sudo -i`, чтобы стать root.

## 5. Установите панель

Выполните **по очереди** две команды. Сначала скачайте установщик:

```sh
curl -fsSL https://raw.githubusercontent.com/minchiki/mc-panel/main/scripts/bootstrap.sh -o bootstrap.sh
```

Теперь запустите его:

```sh
sudo bash bootstrap.sh
```

Что произойдёт: установщик сам поставит Docker, Node.js, nginx и защиту от подбора паролей (fail2ban), скачает панель, соберёт её и запустит. Вы увидите зелёные строки `==>` с этапами. **Займёт это 3-7 минут.** Не закрывайте окно и ничего не нажимайте.

Если на VPS мало памяти (меньше 3 ГБ), установщик сам создаст файл подкачки на 2 ГБ, чтобы сборка не упала.

В конце появится строка:

```
==> done: http://203.0.113.10/
```

Это адрес вашей панели.

> **Остановилось с ошибкой?** Прочитайте красную строку `ОШИБКА` или `ERROR`. Типичные причины описаны в разделе [11](#11-если-что-то-не-работает). Установщик безопасно запускать повторно: вторая попытка продолжит с того же места, ничего не сломав.

## 6. Первый вход

1. Узнайте логин и пароль администратора. Они лежат в файле, который может читать только root:
   ```sh
   cat /root/mc-panel-admin.txt
   ```
   Вы увидите строки `login: admin` и `password: ...`. Пароль длинный и случайный, его проще **скопировать** выделением мыши.
2. Откройте в браузере `http://ВАШ_IP/` (например `http://203.0.113.10/`).
3. Войдите с этим логином и паролем.
4. **Сразу смените пароль:** меню справа вверху → «Аккаунт» → «Пароль».
5. Включите **двухфакторную защиту (2FA)** там же. Понадобится приложение вроде Google Authenticator или аналог. Это защитит панель, даже если пароль утечёт.
6. Когда запомнили или записали новый пароль, удалите файл с первым:
   ```sh
   rm /root/mc-panel-admin.txt
   ```

> Браузер может написать «Не защищено». Это потому, что адрес без HTTPS (по IP шифрование не выдаётся). Для личного пользования приемлемо, а для надёжности подключите домен ([раздел 9](#9-домен-и-https-по-желанию)).

## 7. Создайте сервер Minecraft

1. В панели откройте **«Серверы»** → **«Создать сервер»**.
2. Введите название.
3. Выберите **ядро**:

   | Ядро | Когда выбирать |
   |---|---|
   | **Paper** (по умолчанию) | обычная игра с друзьями, плагины (дом, приваты, экономика), хорошая скорость |
   | **Vanilla** | чистый Minecraft без изменений |
   | **Fabric / Forge / NeoForge** | моды (Sodium, Create, оптимизации и т.д.) |
   | **Purpur / Spigot** | как Paper, с дополнительными настройками |
   | **Velocity / BungeeCord** | «прокси», объединяющий несколько серверов. Новичкам не нужно |

4. Выберите **версию** Minecraft. Она должна совпадать с версией вашего клиента (в лаунчере). Java подберётся автоматически.
5. Укажите **память (RAM)**. Правило: оставьте 1 ГБ запаса от общей памяти VPS. На VPS с 4 ГБ серверу можно дать 2-3 ГБ.
6. Прочитайте и примите соглашение **EULA** Mojang (это обязательное условие запуска сервера).
7. Нажмите «Создать». В консоли сервера пойдёт установка, около минуты. При первом создании сервера панель ещё скачивает образ Java, это может занять до пары минут.
8. Когда появится «Установка завершена», нажмите **«Запустить»**. Первый запуск создаёт мир и идёт 30-90 секунд. Готово, когда в консоли появится строка `Done (...)! For help, type "help"`.

### Полезное в консоли сервера

Команды вводятся в поле консоли без `/`:

| Команда | Что делает |
|---|---|
| `op Ник` | выдать себе права оператора (администратора) |
| `whitelist add Ник` | разрешить зайти конкретному игроку (если включён белый список) |
| `say Привет` | сообщение всем игрокам |
| `stop` | остановить сервер (лучше кнопкой «Остановить») |

## 8. Зайдите на сервер

1. Адрес сервера показан в его карточке в панели. Например `203.0.113.10` (первый сервер) или `203.0.113.10:25566` (если порт не 25565).
2. Запустите Minecraft Java Edition **той же версии**, что вы выбрали.
3. «Сетевая игра» → «Добавить сервер» → вставьте адрес → «Готово» → зайдите.
4. Друзьям отправьте тот же адрес.

> Если вы не можете зайти, а в панели сервер «Запущен», то с вероятностью 90% закрыты порты в файрволе хостера ([раздел 3](#3-откройте-порты)).

## 9. Домен и HTTPS (по желанию)

Домен (например `moy-server.ru`) делает адрес запоминающимся, а HTTPS включает шифрование и убирает предупреждение «Не защищено».

1. Купите домен у любого регистратора.
2. В настройках DNS домена создайте **A-запись**: имя `panel` (получится `panel.moy-server.ru`), значение: IP вашего VPS. Подождите 5-30 минут, пока запись разойдётся.
3. На VPS выполните (подставьте свой домен и почту):
   ```sh
   DOMAIN=panel.moy-server.ru EMAIL=you@example.com bash /opt/mc-panel/scripts/install.sh
   ```
4. Панель будет доступна по `https://panel.moy-server.ru/`.

Для игрового адреса (чтобы друзья вводили `play.moy-server.ru`) настройте записи во вкладке сервера **«Сеть»**: там подсказки по A- и SRV-записям.

## 10. Повседневные дела

### Плагины и моды
Вкладка сервера **«Плагины»** (для Paper и похожих) или **«Моды»** (для Fabric, Forge, NeoForge): поиск по Modrinth, Hangar, SpigotMC и CurseForge (для CurseForge нужен ключ в настройках панели). Нажмите «Установить» и перезапустите сервер.

### Бэкапы
- Вкладка **«Бэкапы»**: кнопка «Создать». Восстановить или скачать можно в один клик.
- Автоматические: вкладка **«Расписание»** → «Бэкап». Укажите, как часто и сколько копий хранить.
- Сама панель сохраняет свою базу каждую ночь автоматически.

> **Важно:** бэкапы лежат на том же VPS. Если VPS удалят или он сломается, пропадут и они. Раз в какое-то время скачивайте важные миры к себе на компьютер.

### Помощники
**Администрирование → Пользователи**: создайте друзьям отдельные аккаунты и выберите, какие разделы им доступны (консоль, файлы, игроки). Пароль админа никому не отдавайте.

### Обновление панели
Кнопка **«Настройки панели» → «Обновить панель»**. Либо в консоли VPS:
```sh
sudo /opt/mc-panel/scripts/update.sh
```
Игровые серверы при этом **не выключаются**. Перед обновлением панель делает свою резервную копию.

### Потерян пароль администратора
```sh
cd /opt/mc-panel/server && sudo -u mcpanel env $(sudo cat /etc/mc-panel/.env | xargs) node dist/cli.js reset-password admin
```
Команда выведет новый пароль.

## 11. Если что-то не работает

### Панель не открывается в браузере
1. Проверьте, что в файрволе хостера открыт порт **80** ([раздел 3](#3-откройте-порты)). Это причина в 9 случаях из 10.
2. Проверьте адрес: `http://` (не `https://`), если домен не подключали.
3. Проверьте, что панель запущена, на VPS:
   ```sh
   systemctl status mc-panel
   curl http://127.0.0.1:3000/api/health
   ```
   Должно быть `active (running)` и ответ `{"ok":true}`. Если нет, посмотрите ошибки: `journalctl -u mc-panel -n 50 --no-pager`.

### Установщик пишет, что не может скачать Docker, Node.js или панель
На VPS проблемы с доступом в интернет или к конкретному сайту. Проверьте:
```sh
curl -I https://github.com
curl -I https://deb.nodesource.com
```
Если не отвечает, подождите и запустите установщик заново (он продолжит с места остановки). Если не помогает, напишите в поддержку хостинга: сайты не открываются с вашего VPS.

### «Установка не удалась: ... нет связи» при создании сервера
Панель не смогла скачать ядро (Paper, Fabric и т.д.) с сайта разработчиков. Теперь в сообщении указан сайт и причина.
1. Нажмите «Установить» ещё раз: бывают временные сбои.
2. Если повторяется, проверьте на VPS: `curl -I https://meta.fabricmc.net` (для Fabric) или `curl -I https://fill.papermc.io` (для Paper).
3. Администратор может открыть в браузере `http://ВАШ_IP/api/admin/network-check`. Там по каждому сайту видно, доступен ли он с вашего VPS и за сколько миллисекунд.

### Сервер сам выключается или «убит» при запуске
Не хватает памяти. Значение «Память» в настройках сервера больше, чем есть свободной RAM у VPS. Уменьшите его (оставьте 1 ГБ запаса) или возьмите VPS побольше. Проверка: `free -h`.

### Друзья не могут зайти
- Открыты ли порты **25565-25665** (TCP) в файрволе хостера?
- Версия Minecraft у друга совпадает с версией сервера?
- Адрес с портом (`IP:25566`), если сервер не первый?
- Включён ли белый список (`whitelist`) и добавлен ли друг?

### «Порт занят» / сервер не стартует
Выберите другой порт в настройках сервера (вкладка «Сеть») из диапазона 25565-25665.

### Docker не запускается
```sh
systemctl enable --now docker
docker info
```
Если `docker info` выдаёт ошибку, значит на VPS нельзя запускать контейнеры (так бывает на некоторых типах виртуализации). Закажите VPS на KVM.

### Нужна помощь
Откройте вопрос (Issue) в репозитории проекта. Приложите: название хостинга, версию Ubuntu (`lsb_release -a`) и **последние 30 строк** вывода: `journalctl -u mc-panel -n 30 --no-pager`. Пароли и IP из вывода можно замазать.

## 12. Безопасность

VPS в интернете **сразу** начинают проверять боты: подбирают пароли. Несколько простых правил:

1. **Пароль root должен быть длинным и уникальным.** Лучше 16+ символов. Не используйте его нигде больше.
2. **Сменяйте пароль администратора панели** и включайте 2FA ([раздел 6](#6-первый-вход)).
3. **Не открывайте лишние порты** в файрволе. Нужны только те, что в [разделе 3](#3-откройте-порты).
4. Панель сама банит подбор паролей (fail2ban): 8 неудачных попыток подряд дают бан на час.
5. **Никому не давайте пароль root и пароль админа панели.** Друзьям создавайте отдельные аккаунты с ограниченными правами.
6. Раз в месяц обновляйте систему: `apt update && apt upgrade -y`, и панель: «Обновить панель».
7. **Продвинутым:** вместо пароля для SSH используйте ключи и запретите вход по паролю.

## 13. Как удалить панель

> Это **безвозвратно удалит все серверы, миры и бэкапы.** Сначала скачайте всё нужное.

```sh
systemctl disable --now mc-panel mc-panel-update.path mc-panel-backup.timer
docker ps -aq | xargs -r docker rm -f
rm -rf /opt/mc-panel /var/lib/mc-panel /srv/minecraft /etc/mc-panel /var/log/mc-panel /var/backups/mc-panel
rm -f /etc/systemd/system/mc-panel*.service /etc/systemd/system/mc-panel*.path /etc/systemd/system/mc-panel*.timer
rm -f /etc/nginx/sites-enabled/mc-panel /etc/nginx/sites-available/mc-panel
systemctl daemon-reload && systemctl reload nginx
```

Либо просто удалите VPS в личном кабинете хостинга.
