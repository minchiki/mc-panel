# Интерфейс панели MC Panel (названия кнопок и разделов)

## Левое меню
- **Серверы**: список ваших серверов, статус (Выключен, Установка, Запускается, Онлайн, Останавливается, Упал).
- **Создать сервер**: мастер создания (название, ядро, версия, память, EULA).
- **Аккаунт**: смена пароля, включение 2FA, API-ключи.
- **Администрирование** (только для админа): Обзор VPS, Пользователи, Журнал действий, Системные логи, Настройки панели.
- Внизу: Тема (тёмная/светлая), Язык, Выйти.

## Страница сервера
Вверху карточки CPU, Память, Игроки, Диск и кнопки питания:
- **Запустить**; **Остановить** (сохраняет мир и выключает корректно); **Перезапустить**;
- **Убить процесс** (мгновенно, без сохранения мира; только если сервер завис).

Вкладки сервера:
| Вкладка | Что там |
|---|---|
| **Консоль** | вывод сервера в реальном времени, поле для команд (без `/`) |
| **Файлы** | файловый менеджер с редактором: загрузка, скачивание, правка конфигов |
| **Плагины** или **Моды** | каталог Modrinth, Hangar, SpigotMC, CurseForge. Название зависит от ядра. Для CurseForge нужен ключ в «Настройки панели» |
| **Игроки** | кто онлайн, пинг, права оператора, белый список, баны |
| **Настройки** | «Ресурсы и запуск» (память, CPU, диск, Java), «Ядро и версия», server.properties с превью MOTD, «Опасная зона» (сброс мира/модов, удаление сервера) |
| **Бэкапы** | создать, восстановить, скачать; параметры (сколько копий хранить) |
| **Расписание** | задачи по времени: бэкап, перезапуск, команда |
| **Мониторинг** | графики CPU, памяти, игроков |
| **Базы данных** | MariaDB для плагинов: создать базу, получить логин и пароль |
| **Сеть** | «Адрес подключения», «Порт и домен», «Как привязать домен» (A- и SRV-записи) |
| **Доступ** | кто из помощников что может делать на этом сервере (только владелец) |

Изменения в настройках обычно вступают в силу после перезапуска сервера.

## Администрирование
- **Обзор VPS**: нагрузка, память, диск хоста, список всех серверов.
- **Пользователи**: создать аккаунт помощнику, роль и права, сброс пароля.
- **Журнал действий**: кто и что делал в панели.
- **Системные логи**: логи служб mc-panel, docker, nginx, fail2ban, ssh.
- **Настройки панели**: уведомления Telegram/Discord, ключ CurseForge, кнопка «Обновить панель».

## Диагностика сети (для админа)
Адрес `http://IP/api/admin/network-check` (в браузере, где выполнен вход админом) показывает, доступны ли с VPS сайты, откуда панель качает ядра: Mojang, Fabric, Paper, Purpur, Forge, NeoForge, Modrinth, Hangar. Для каждого: ok/не ok, время и причина.

## Частые сообщения об ошибках
- «<сайт>: не удалось подключиться за 10 секунд ... Это проблема сети между VPS и этим сайтом»: VPS не может открыть сайт разработчиков ядра. Повторить; проверить `curl -I https://<сайт>` на VPS; открыть network-check; если не помогает, написать в поддержку хостинга.
- «Установка не удалась»: смотреть текст ошибки в консоли сервера; нажать «Установить» ещё раз.
- Сервер «Упал» (crashed): смотреть последние строки консоли; чаще всего не хватает памяти или несовместимый мод/плагин.

## Уведомления в Telegram и Discord (Администрирование - Настройки панели - «Уведомления»)
- Создайте бота у @BotFather, скопируйте токен в поле «Токен Telegram-бота». Chat ID своего аккаунта узнайте у @userinfobot (для группы число с минусом).
- Переключатели «О чём уведомлять»: «Сервер запущен», «Сервер остановлен», «Сервер упал», «Бэкап создан», «Бэкап не удался», «Мало места на диске». По умолчанию включены падения, ошибки бэкапа и нехватка диска.
- Кнопка «Сохранить и отправить тест» шлёт проверочное сообщение. Если Telegram на VPS заблокирован, раскройте блок «Telegram заблокирован на VPS? Через relay» и укажите адрес и ключ relay.
- Одно и то же уведомление по одному серверу приходит не чаще раза в 10 минут, чтобы не засорять чат.

## Новая версия панели
- Администратор видит полосу «Доступна новая версия панели» под шапкой. Кнопка «Обновить» ведёт в «Настройки панели - Обновление панели». Полосу можно скрыть кнопкой «Скрыть».
- Если установленная версия не найдена на GitHub (например, вы вносили свои изменения), полосы не будет: это нормально.
